# SoleKey 1.0.0

Windows용 로컬 계정·비밀번호 금고입니다. 계정 정보를 암호화해 PC에 보관합니다.

## 다운로드

[최신 릴리스](https://github.com/Song-Sungyoub/sole-key/releases/latest)에서 받습니다.

- **MSI 설치 파일**: 현재 사용자 계정에 설치하며 시작 메뉴와 바탕 화면 바로가기를 만듭니다.
- **ZIP 실행본**: 압축을 풀고 `SoleKey.exe`를 실행합니다.
- 두 배포본 모두 .NET 런타임을 포함합니다. Windows x64가 필요합니다.
- `SHA256SUMS.txt`로 다운로드한 파일의 SHA-256을 확인할 수 있습니다.

## 사용 방법

1. ‘새 금고 만들기’를 선택하고 저장 위치를 지정합니다. 기본 이름은 `SoleKey.solekey`입니다.
2. 15~128자의 마스터 비밀번호와 확인을 입력합니다. 비밀번호를 잊으면 복구할 수 없습니다.
3. 계정을 추가하고 사용처, ID, 비밀번호, 메모를 입력합니다. ID가 필요 없으면 ‘ID 사용’을 해제합니다.
4. `+` 버튼으로 2차 비밀번호 등 여러 비밀번호를 등록합니다.
5. 사용처·ID·메모를 검색하고 눈 아이콘으로 비밀번호를 보거나 복사합니다.
6. 금고 관리에서 암호화 백업·복원과 마스터 비밀번호 변경을 수행합니다.

금고 위치를 기억하므로 다음 실행에서는 마스터 비밀번호만 입력하면 됩니다. 파일을 옮겼다면 위치를 다시 선택합니다.

## 트레이와 잠금

- 창 닫기·최소화는 트레이로 보관합니다.
- 트레이 더블클릭, ‘SoleKey 열기’, 실행 파일 재실행은 기존 창과 해제 상태를 복원합니다.
- 트레이 보관 중에는 앱 미사용 자동 잠금을 멈춥니다. 복귀 시 타이머를 다시 시작합니다.
- 수동 잠금·Windows 세션 잠금·완전 종료 후에는 다시 비밀번호를 입력해야 합니다.
- **완전 종료는 트레이 메뉴의 ‘종료’**를 선택합니다.

창을 표시한 상태에서 기본 5분간 사용하지 않으면 잠깁니다. 자동 잠금 시 미저장 편집 내용은 폐기됩니다. 편집 내용은 저장 버튼으로 확정하세요.

## 데이터 보관

- 사용처·ID·비밀번호·메모 전체를 JSON으로 직렬화한 뒤 AES-256-GCM으로 암호화합니다.
- 마스터 비밀번호와 금고별 무작위 salt에서 Argon2id로 키를 유도합니다. 기본 파라미터는 64MiB, 반복 3회, 병렬도 1입니다.
- 마스터 비밀번호와 암호화 키는 디스크에 저장하지 않습니다.
- 최근 금고 경로와 시간 설정만 `%LOCALAPPDATA%/SoleKey/settings.json`에 보관합니다.
- 백업도 암호화된 파일입니다. 복원 전 현재 금고를 별도 백업합니다.
- 비밀번호 변경은 이전 백업에 소급되지 않습니다. 이전 백업은 당시 비밀번호로 엽니다.
- 앱 제거는 사용자가 저장한 금고와 설정을 삭제하지 않습니다.

파일 최대 16MiB, 복호화한 JSON 최대 10MiB, 계정 10,000개, 항목당 비밀번호 100개를 지원합니다.

## 보호 범위

저장 암호화는 실행 중인 PC의 악성코드까지 막지 못합니다. 클립보드 기록·동기화나 다른 앱이 복사한 내용은 지울 수 없으며, .NET 문자열의 모든 메모리 사본을 즉시 소거한다고 보장하지 않습니다.

첫 공개 버전은 독립 보안 감사를 받지 않았고 코드 서명이 적용되지 않았습니다. 동기화·브라우저 자동 입력·계정 공유·마스터 비밀번호 복구·자동 업데이트는 포함하지 않습니다.

## 개발·검증

Windows와 .NET 8 이상 SDK를 사용합니다.

```powershell
dotnet build SoleKey.sln -c Release
dotnet run --project Checks/SoleKey.Checks.csproj -c Release
pwsh -NoProfile -File Installer/Build.ps1
```

자동 검증 109개는 임시 금고와 가상 데이터를 사용합니다. 실제 사용자 금고·설정을 수정하지 않습니다. 창·트레이·재실행 신호·금고 암복호화·변조 거부·저장 실패 보존 등을 검증하며, 다중 DPI와 실제 OS 잠금의 실기 확인은 별도입니다.

아이콘 원본은 `Assets/Icon/Icon.xaml`이며 PowerShell 7 STA에서 `Assets/Icon/build-icon.ps1`로 크기별 PNG와 ICO를 재생성합니다.
